STAY IN CHARACTER, STAY RESPECTFUL

Server Rules

City එකේ හැම කෙනෙක්ටම හොඳ roleplay experience එකක් ලබා දෙන්න, කරුණාකර මේ rules follow කරන්න. Rules violate කළොත් warning, kick, හෝ ban එකකට යටත් වෙන්න පුළුවන්.

01 · General Conduct

  1. විනීතව හැසිරෙන්න. Staff, other players, සමඟ respect එකෙන් කතා කරන්න — real life වගේම, in-character වශයෙන්ම.
  2. Racism, homophobia, hate speech, harassment — කිසිම විදිහකට allow කරන්නෙ නෑ. Instant ban එකකට වගේ බලපානවා.
  3. වැරදි වචන (bad words / slurs) voice chat, text chat, character names වල use කරන්න එපා.
  4. Age-appropriate කතාබහක් තියාගන්න — 18+ content, real-world violence threats, etc. සම්පූර්ණයෙන්ම තහනම්.
  5. Staff member කෙනෙකුගේ තීරණයකට කැමති නැත්නම්, argument එකක් server එකේ නොකර, Discord support ticket එකකින් appeal කරන්න.

02 · Roleplay Standards

  1. RDM (Random Death Match) — reason එකක් නැතුව වෙන player කෙනෙක්ව kill/attack කරන්න එපා. හැම action එකකටම IC (in-character) reason එකක් තියෙන්න ඕන.
  2. VDM (Vehicle Death Match) — වාහන use කරලා intentional ලෙස වෙන player කෙනෙක්ට හානි කරන්න එපා.
  3. Metagaming — OOC (out-of-character, උදා: Discord, stream) මාර්ගයෙන් ලැබෙන info එකක් IC actions වලට use කරන්න එපා.
  4. Powergaming — physically/logically කරන්න බැරි actions (force කරලා) කරන්න එපා (උදා: escape කරන්න බැරි ලෙස player කෙනෙක්ව restrain කරලා, reaction time දෙන්නෙ නැතුව actions කරන එක).
  5. Fail RP — realistic නොවන ලෙස react කරන්න එපා (උදා: gun point එකේ ඉඳන් fight කරන්න යාම, injury එකක් ignore කරලා normal ලෙස ක්‍රියා කිරීම).
  6. New Life Rule (NLR) — character කෙනෙක් die වුනාට පස්සේ, කලින් සිද්ධියේ knowledge එක අමතක කරන්න ඕන.

03 · Technical & Fair Play

  1. Cheats, hacks, exploit කිසිම විදිහක use කරන්න බෑ — detect උනොත් permanent ban.
  2. Bugs/exploits හම්බුනොත් misuse කරන්නෙ නැතුව, admin කෙනෙකුට report කරන්න.
  3. Multiple accounts use කරලා rules bypass කරන්න (ban evading) තහනම්.
  4. Advertising වෙන servers/services, spam කිරීම chat එකේ තහනම්.

04 · Whitelist & Character

  1. Whitelist approval එකකින් පස්සේ, ලැබෙන character name එකෙන්ම play කරන්න ඕන.
  2. Character name එක realistic (First_Last format) විදිහට තියාගන්න — offensive/joke names allow කරන්නෙ නෑ.
  3. Whitelist application එකේ දුන්න details (age, real name) accurate විය යුතුයි.
